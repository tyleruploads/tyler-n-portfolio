About Tyler N

I am Tyler N., a self-taught coder from Maryland in the 8th grade. Coding is mentally rewarding and very stimulating for me because I get to solve problems with very specific, concrete methods. Because of my age, I have not committed to any specific type of coding so far. But, I tend to really enjoy Web and App development.

My Background Story

When I was much younger, I used to "code" a bit, while really just trying to have AI create entire applications for me. But, in the sixth grade, I began to learn to code on my own, and I caught on very quickly. I realized that when I was younger, I was missing out on the best part of coding: the learning.

I now occasionally use AI like documentation or for catching errors, and I know that it should never be used to actually write code for you. To pick up coding quickly, I followed through with the Python Crash Course book by No Starch Press, treating each chapter like a unit at school where you need to demonstrate you actually understand each section. For every other coding language, I learned by doing. I found basic examples of things in that language, researched how to do specific things, then just did them.

My Other Hobbies
